# Data display policy

The interface is intentionally **trend first**.

For computed experiments, the preferred order is:

1. plot / trajectory / trend;
2. a short vertical key-results table with readable precision and units;
3. a `More data / complete data` control;
4. only after that control is enabled, build and render the full numerical table and provide its CSV download.

This avoids both extremes: important numbers are visible without forcing the user through a giant raw table, while complete data remains available when needed.
